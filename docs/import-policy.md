## Сработавшие шаблоны (проверка)

- `bin/build.txt` — исключён шаблоном `bin/`.
- `.env` — исключён шаблоном `/.env` (точное имя в корне).
- `.env.example` — **не игнорируется**, доступен для добавления.
- `.vscode/extensions.json` — **доступен** благодаря правилу `!/.vscode/extensions.json`.
- `docs/drafts/keep.md` — **доступен** благодаря правилу `!/docs/drafts/keep.md`.

## Изменение временного файла `notes.tmp`

1. `*.tmp` добавлен в `.gitignore` **после** первого коммита, в котором `notes.tmp` уже отслеживается. `.gitignore` влияет только на **неотслеживаемые** файлы. Уже отслеживаемый файл продолжает отображаться в `git status` как изменённый, даже если совпадает с шаблоном игнора.
2. При проверке с флагом `--no-index` Git анализирует файл так, будто он **не в индексе**. Поэтому срабатывает правило `*.tmp`. Без `--no-index` Git видит, что файл уже отслеживается, и **не** применяет правила игнора.

**Отличие исключения новых файлов от прекращения отслеживания:** исключение новых файлов через `.gitignore` предотвращает попадание в индекс файлов, которые ещё не отслеживаются. Прекращение отслеживания (`git rm --cached`) удаляет файл из индекса, но **оставляет его на диске**.
